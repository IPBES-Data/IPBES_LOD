This directory contains the IPBES Scenarios and Models of Biodiversity and Ecosystem Services Assessment (SCM) in LOD format. DOI: https://doi.org/10.5281/zenodo.22277985


The structure of the file follows the IPBES ontology version 06:
https://github.com/IPBES-Data/IPBES_Ontology

The assessment report is published in 2016 and consists of 8 chapters and a Summary for Policy Makers (SPM).

For more information about this report, see: https://www.ipbes.net/assessment-reports/scenarios 

For the full report, see: https://doi.org/10.5281/zenodo.3235429

For information on how to cite the BBA report, see: https://ict.ipbes.net/ipbes-ict-guide/data-and-knowledge-management/technical-guidelines/suggested-citations#xiv.-scenarios-and-models-assessment
