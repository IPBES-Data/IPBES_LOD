This directory contains the IPBES Nexus Assessment in LOD format.
DOI: https://doi.org/10.5281/zenodo.23664985 

The structure of the file follows the IPBES ontology version 06:
https://github.com/IPBES-Data/IPBES_Ontology

The assessment report is published in 2024 and consists of 7 chapters and a Summary for Policy Makers (SPM).

For more information about this report, see: https://www.ipbes.net/nexus-assessment

For the full report, see: https://doi.org/10.5281/zenodo.13850054

For information on how to cite the NXS report, see: https://ict.ipbes.net/ipbes-ict-guide/data-and-knowledge-management/technical-guidelines/suggested-citations#iii.-nexus-assessment
