This directory contains the IPBES Business and Biodiversity Assessment (BBA) in LOD format. DOI: https://doi.org/10.5281/zenodo.22281278


The structure of the file follows the IPBES ontology version 06:
https://github.com/IPBES-Data/IPBES_Ontology

The assessment report is published in 2026 and consists of 6 chapters and a Summary for Policy Makers (SPM).

For more information about this report, see: https://www.ipbes.net/business-impact 

For the full report, see: https://doi.org/10.5281/zenodo.17185117

For information on how to cite the BBA report, see: https://ict.ipbes.net/ipbes-ict-guide/data-and-knowledge-management/technical-guidelines/suggested-citations#i.-business-and-biodiversity-assessment
